DATENSCHUTZ

Base ist eine private App, die nur von mir selbst genutzt wird.

Welche Daten

Mit meiner Zustimmung liest Base meine Google-Kalender und trägt Termine ein, die ich selbst erfasse (Google Calendar API).

Wo die Daten bleiben

Alle Daten werden ausschliesslich auf meinem eigenen Server bei mir zu Hause verarbeitet und gespeichert. Es gibt keine Weitergabe an Dritte, keine Werbung, kein Tracking und keinen Verkauf von Daten.

Nutzung von Google-Daten

Die Nutzung von Daten, die über Google-APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.
